# Bank Form Autofill

A Chrome extension that fills bank transfer forms in one click, using the floating bubble or a hotkey.

[![Download](https://img.shields.io/badge/Download-ZIP-1a73e8?style=for-the-badge)](https://github.com/mdshakiburrahman6/Auto-Filler-Extention/archive/refs/heads/main.zip)

## Install (Chrome / Edge / Brave)

1. Download the ZIP above and unzip it.
2. Open `chrome://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the unzipped folder. This is the folder that directly contains `manifest.json`.
5. The settings page opens. Enter your bank details and click **Save**.
6. Pin the extension (puzzle icon > pin) so you can reopen settings anytime.

## Use

1. Open the redeem page. A blue ⚡ bubble appears when the bank form is visible.
2. Click the bubble, or press your hotkey (default **Alt + F**, changeable in settings).
3. With 2 or more profiles, the bubble shows a menu so you can pick one.
4. Review the fields, then click **Transfer** yourself.

## Notes

- Your details are stored only in your browser's extension storage.
- Never commit real bank details to this repository.
